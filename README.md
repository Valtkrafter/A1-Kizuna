# A1-Kizuna
A1 Kizuna is a calm, keyboard-driven Japanese A1 trainer built for placement tests. Modeled after Busuu, it pairs concise grammar sheets with focused 5-sentence drills (cloze and word puzzles). Clean Kana/Kanji reveals Romaji and audio on hover, backed by strict linear progression and a dark mode designed to build fast grammatical intuition.
